# NotificationSystem
## Описание

Система уведомлений
NotificationSystem — это мощная и гибкая система уведомлений, предназначенная для автоматизации рассылки сообщений 
пользователям через различные каналы связи: Telegram, электронную почту SMS. В основе системы лежат передовые технологии,
включая Go, PostgreSQL, RabbitMQ и GRPC, что делает её производительной, стабильной и масштабируемой. Этот инструмент станет
отличным выбором для бизнеса, которому важно своевременно информировать клиентов о важных событиях, акциях, новостях или
изменениях в статусе заказов. Благодаря гибкой модульной структуре, NotificationSystem легко встраивается в уже существующие процессы и может быть настроена под конкретные требования компании.

Система состоит из четырех сервисов:
- bd: База данных Postgresql, хранящая контактные данные: ФИ, телефон, телеграмID и e-mail.
- notification-service: Сервис на golang, который взаимодействует с базой данных и по протоколу grpc получает сообщения от
message-broker, запускает рассылку уведомлений через телеграм API, и на e-mail(по протоколу SMTP)
- queue: Брокер сообщений RabbitMQ, получающий сообщения из всевозможных источников с информацией об уведомлении, которое необходимо отправить.
- message-broker: Сервис написанный так же на golang, обеспечивающий взаимодействие с очередью queue и 
передающий поступающие сообщения сервису notification-service по grpc.

## Установка

1. Клонировать репозиторий
   git clone https://github.com/Kitores/NotificationSystem.git

2. Запустить из корневой директории сборку командой
   docker-compose up --build

## Технологии

- **Message-Broker**: RabbitMQ
- **Backend**: Go, gRPC
- **Database**: Postgresql
- **Containerization**: Docker, Docker Compose
